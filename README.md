of IYF Season 12 Week 1 Web Foundations.

## How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Navigate through the different pages using the navigation menu.

## Lessons Learned

During Week 1, I learned how to:

- Create HTML documents using proper structure.
- Use headings, paragraphs, links, images, and lists.
- Build multi-page websites.
- Create navigation menus.
- Use semantic HTML elements.
- Create accessible forms.
- Use labels and required form fields.
- Use Chrome DevTools to inspect webpages.
- Perform an accessibility audit using Lighthouse.

## Challenges Faced

One of the challenges I faced was understanding how different
semantic HTML elements should be used.

I also had to learn how to organize multiple HTML pages and make
sure the navigation links worked correctly between them.

Another challenge was understanding accessibility requirements,
especially the importance of labels, alternative text, and semantic
HTML.

Working through these challenges helped me understand how to build
better structured and more accessible websites.
